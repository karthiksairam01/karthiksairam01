| 📄 **[Chat with My Research](https://github.com/karthiksairam01/ai-research-chatapp)** | An interactive RAG-powered web application that allows users to ask questions about my NLP research paper. | 🛠️ **[CMV Relationship Annotation Tool](https://github.com/karthiksairam01/cmv_annotation)** | Built a command-line tool to streamline the manual annotation of conversational data from Reddit.
